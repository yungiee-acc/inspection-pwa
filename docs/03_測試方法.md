## 三、你部署後的驗收清單（約 15 分鐘）
1. 管理員登入成功；用另一個「查驗人員」帳號登入，確認看不到「環資配對／報告／管理」。
2. 查驗人員手機輸入一筆 → 管理員電腦在「查驗紀錄」看得到（證明共用資料庫）。
3. 手機開飛航模式再存一筆 → 看到「已暫存」橫幅 → 關閉飛航 → 自動上傳，只有一筆。
4. 辦公室匯入 `tests/samples/hz_20261109.xls` → 配對 → 報告草稿 → 管理員審核 → 下載 Excel，與範例比對。
5. 兩支手機同時編輯同一筆 → 後存的人看到「剛被其他人修改」。
6. Supabase 後台 Table Editor 看 `audit_log` 有紀錄。
