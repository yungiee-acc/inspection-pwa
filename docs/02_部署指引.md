# 部署指引（一步一步，不需要程式背景）

整體架構：**GitHub Pages**（放網頁）＋ **Supabase**（共用資料庫、登入、權限）。兩者都有免費方案。

## 費用與限制（2026-11 查證，請以官網為準）
| 項目 | 免費額度／限制 | 對你的影響 |
|---|---|---|
| Supabase Free | 資料庫 500 MB、檔案儲存 1 GB、流量 5 GB/月、5 萬月活躍使用者；**專案閒置 1 週會被暫停**；**不含自動備份**；最多 2 個專案 | 本系統資料量很小（一天數十筆），500 MB 可用很多年。**暫停**：平日有人用就不會；長假前後記得登入喚醒。**備份**：必須自己定期按「管理→備份」下載。 |
| Supabase Pro | 約 US$25/月起 | 若要自動每日備份、不被暫停才需要。 |
| GitHub Pages | 網站 ≤1 GB、流量軟上限 100 GB/月；公開儲存庫免費（私人儲存庫是否可用取決於方案，請在 GitHub 確認） | 程式碼會是公開的 → **不要把廠商主檔、環資、報告放進儲存庫**（見第 3 步）。資料安全靠 Supabase 登入與 RLS，不靠隱藏網址。 |

> 若你希望程式碼也不公開，可改用 Cloudflare Pages / Netlify（免費方案可接私人儲存庫），本系統只是靜態網頁，搬過去不用改程式。

## 第 1 步：建立 Supabase 專案
1. 到 supabase.com 註冊並建立 Project（Region 選 Northeast Asia / Tokyo 或 Singapore）。**資料庫密碼自己記好**。
2. 左邊 **SQL Editor** → New query → 貼上 `supabase/schema.sql` 全部內容 → Run（顯示 Success）。
3. 再 New query → 貼上 `supabase/seed.sql`（ERP 品號與廠商）→ Run。
4. **Authentication → Providers → Email**：把 **「Allow new users to sign up」關掉**（只由管理員建立帳號），登入方式暫用 Email＋Password。
5. **Authentication → Users → Add user**：建立三個帳號（填 Email、密碼，勾 Auto Confirm）：一般使用者、審核者、後台管理者。密碼請自己設定並保管（我無法替你建立帳號）。
6. 打開 `supabase/accounts.sql`，把三個信箱換成你剛建立的，貼到 SQL Editor 執行，即設好角色並啟用。
7. **Project Settings → API**：複製 **Project URL** 與 **anon public** 金鑰。⚠ 不要用 `service_role` 金鑰。

## 第 2 步：填入設定
開啟 `app/js/app-config.js`，填入：
```js
SUPABASE_URL: 'https://xxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJ....（anon public 金鑰）',
```
anon 金鑰設計上本來就會出現在網頁中，安全由資料庫的 RLS 規則把關。

## 第 3 步：放到 GitHub Pages
1. 在 GitHub 建立新儲存庫（例如 `inspection-pwa`）。
2. 上傳**整個專案**，但**不要**上傳：`tests/samples/`、`tests/output/`、你的四個原始 Excel、`supabase/seed.sql`（含廠商資料）。專案內的 `.gitignore` 已排除這些。
   - ⚠ `app/data/vendors.json` 也含廠商名稱與統編。正式模式不需要它（廠商來自資料庫），**部署前請刪除 `app/data/vendors.json` 與 `erp_items.json`**（`sw.js` 已不預快取它們，刪除不影響）。
3. 儲存庫 **Settings → Pages** → Source 選 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)`；若想直接以 app 資料夾為網站根目錄，可用 GitHub Actions 發佈 `app/`，或把 `app/` 的內容放到儲存庫根目錄。
4. 等 1～2 分鐘取得網址（如 `https://帳號.github.io/inspection-pwa/app/`）。

## 第 4 步：手機安裝與建立使用者
1. 手機 Chrome（Android）或 Safari（iPhone）開網址 → 選單「加入主畫面／安裝應用程式」。
2. 後台管理者登入 → **管理 → 使用者**：新增的帳號預設「停用」，在此設姓名、角色（查驗人員／辦公室／管理員）並改為「啟用」。新帳號到 Supabase **Authentication → Users → Add user** 建立。
3. 例行：每週「管理 → 備份」下載一次 JSON，存雲端硬碟。

## 本機先試用（不需要網路帳號）
不填 `app-config.js` 即為**示範模式**（資料只在該瀏覽器，不同步）。啟動方式：
```
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```
瀏覽器開 http://localhost:8080/app/ 。

## 更新主檔
ERP 主檔或廠商主檔變動時：執行 `tools\extract_masters.ps1` → `tools\make_seed.ps1` → 把新的 `seed.sql` 貼到 SQL Editor 執行（不會覆蓋管理員已補的對照名稱）。
